# PostgreSQL MCP

Queries a PostgreSQL database. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/@modelcontextprotocol/server-postgres

Installs from the Camillia hub as `postgresql-mcp-066b62`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
